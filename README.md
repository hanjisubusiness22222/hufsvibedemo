# HUFS TA-Mate (외대 조교 메이트) 데모

2026 한국외대 AI 캠퍼스: 바이브코딩 경진대회 프로토타입 데모 사이트입니다.

## 🚀 프로젝트 개요
한국외대 공식 사이트(학사일정/공지/서식) 연동 및 네이버클라우드(HyperCLOVA X)·Gemini를 활용한 **대학원·학부 조교 업무 표준화 및 자동 인수인계 플랫폼**

## 💡 주요 기능
1. **외대 학사일정 D-Day 연동 대시보드:** 마감 임박 업무 및 학사종합지원센터 직통 내선 자동 매칭
2. **타교·타과 출신 신임 조교 & 신임 학부장 온보딩 가이드:** 외대 행정 시스템 요약 및 학과 전공 특성 안내
3. **스마트 문서 아카이브 & AI 문서 자동 변환:** 전임자의 과거 문서를 올해 학사일정 및 최신 반려 방지 기준으로 자동 리뉴얼
4. **대학원·학부 공유 업무 일지 & 인수인계 마법사:** 일지 작성만으로 표준 인수인계서 자동 컴파일

## 🖥️ 바로 실행하기
`index.html` 파일을 웹 브라우저로 열거나 배포된 URL을 통해 즉시 체험하실 수 있습니다.
